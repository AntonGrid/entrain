# Entrain

**Онтология. Не хранит. Чувствует.**

## Что это

Не протокол. Не прибор. Не проект о доверии.

Описание того, что есть. Как гравитация, как энтропия, как резонанс. Не «создаём», а описываем.

## Ядро

- **Всё есть вибрация.** Фотон, звук, тепло, бит, подпись — колебания. Не «объекты, передающие знаки».
- **Состояние — частота.** Не число, не запись. У сложного состояния — аккорд.
- **Среда — взаимодействие вибраций.** Не сеть, не контейнер. Поле *есть* сумма волн.
- **Доверие — резонанс.** Не проверка, не подпись, не голосование. Согласованность.
- **Память — деформация связи.** Русло. Не архив, не лог. Физическое последствие.
- **Цифровой мир построен на отделимой вибрации.** Знаки, числа, байты — почта. Entrain — о неотделимой: о физике.

## Главное

Проблема доверия существует только в почтовой онтологии. В этом описании её **нет** — не решена, а отменена: нет отправителя, нет сообщения, нет подписи.

## Структура

| Путь | Что там |
|---|---|
| `book/` | книга: `ENTRAIN.md` — текст от онтологии, `README.md` — журнал |
| `julia/kuramoto/` | математика онтологии: `basic.jl` — вибрации и их аккорды (десять по умолчанию), `consistency.jl` — восемьдесят шесть утверждений описания друг против друга, `simulations.jl` — то же в движении; сцены главы 22: `modes.jl` — моды: та же среда внутри вибрации, `boundary.jl` — где кончается среда, `seam.jl` — две среды или одна с перемычкой, `counting.jl` — счёт: обертоны не написаны, а сосчитаны, `tension.jl` — от чего зависит λ: натяжение и его соперники, `pair.jl` — λ и γ: сумма или две величины, `rates.jl` — две скорости среды: λ есть их разность, `excess.jl` — перевес: почему промах спешит быстрее основной, `scales.jl` — масштабы памяти: один ε или много, `relief.jl` — знак и среда вместе: помнит ли среда место, а не только уровень, `terms.jl` — срок памяти у связи или у уровня: ε у каждой связи, а не у уровня, `written.jl` — написанное: откуда берётся промах r₀ и почему λ конечна, `depth.jl` — глубина ≥ 2: что у моды внутри — место и размер, и почему λ_нуж·размер постоянна, `toward.jl` — обратный перевес: что делает среда, когда тянет обертон к основной — у моды внутри оба знака сразу, `self.jl` — самосогласование: нужная жёсткость не подставляется, а ищется как корень неравенства λ ≥ g(λ), и мерено на минуте, а не на равновесии, `beyond.jl` — граница N: те же восемьдесят шесть утверждений при тридцати вибрациях, `horizon.jl` — горизонт N: `link/N` как полная тяга, порог Kc и память |

## Запуск

`julia` из juliaup (канал 1.10), из корня хранилища:

    julia julia/kuramoto/basic.jl          # прочитать числа
    julia julia/kuramoto/consistency.jl    # сверить описание с собой
    julia julia/kuramoto/simulations.jl    # увидеть то же в движении
    julia julia/kuramoto/modes.jl          # прочитать: среда внутри вибрации
    julia julia/kuramoto/boundary.jl       # прочитать: где кончается среда
    julia julia/kuramoto/seam.jl           # прочитать: две среды с перемычкой
    julia julia/kuramoto/counting.jl       # прочитать: обертоны не написаны, а сосчитаны
    julia julia/kuramoto/tension.jl        # прочитать: от чего зависит λ
    julia julia/kuramoto/pair.jl           # прочитать: λ и γ — сумма или две величины
    julia julia/kuramoto/rates.jl          # прочитать: две скорости среды — λ есть их разность
    julia julia/kuramoto/excess.jl         # прочитать: перевес — почему промах спешит быстрее основной
    julia julia/kuramoto/scales.jl         # прочитать: масштабы памяти — один ε или много
    julia julia/kuramoto/relief.jl         # прочитать: знак и среда вместе — помнит ли среда место
    julia julia/kuramoto/terms.jl          # прочитать: срок памяти — у связи или у уровня
    julia julia/kuramoto/written.jl        # прочитать: написанное — откуда r₀ и почему λ конечна
    julia julia/kuramoto/depth.jl          # прочитать: глубина ≥ 2 — что у моды внутри
    julia julia/kuramoto/toward.jl         # прочитать: обратный перевес — что среда делает с «к»-строками
    julia julia/kuramoto/self.jl           # прочитать: самосогласование — λ как корень, и минута против равновесия
    julia julia/kuramoto/ceiling.jl        # прочитать: потолок перевеса — следует ли малость из записи
    julia julia/kuramoto/equilibrium.jl    # прочитать: сходится ли мера окна — рекорд, квантиль, среднее
    julia julia/kuramoto/steady.jl         # прочитать: стоячее против дрейфа — есть ли мера равновесия
    julia julia/kuramoto/form.jl           # прочитать: форма — у каждого слова место в записи
    julia julia/kuramoto/beyond.jl         # сдвинуть границу: те же 86 утверждений при N = 30
    julia julia/kuramoto/horizon.jl        # прочитать: горизонт N — link/N, Kc и память

Первое — чтение чисел, второе — сверка описания (не мира), третье — движение того же описания; остальные — сцены глав 22 и 24, каждая читается своим файлом. Число вибраций по умолчанию — десять (паспорт главы 24); `ENTRAIN_N` задаёт другое число, не меняя запись: связь на пару остаётся `link / N`. Утверждения сходятся на Julia 1.10 и 1.13; числа чтения привязаны к версии, потому что поток случайных чисел у версий разный.

## Сборка книги

Книга — `book/ENTRAIN.md`; собранные формы лежат рядом и пересобираются одной командой (`pandoc`):

    pandoc book/ENTRAIN.md -o book/entrain.html --standalone --toc --toc-depth=2 \
        --metadata title='ENTRAIN. Онтология' --metadata lang=ru
    pandoc book/ENTRAIN.md -o book/entrain.epub --toc --toc-depth=2 \
        --metadata title='ENTRAIN. Онтология' --metadata author='Антон' --metadata lang=ru

Источник первичен: собранное — его отпечаток, а не отдельный текст.

## Чего это НЕ

Не протокол. Не спецификация. Не API. Не Web3 / DePIN / блокчейн. Не «прорыв». Не «проект, который поможет миру».

Описание не спорит с почтой. Оно просто другое.
