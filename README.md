# Entrain

**Онтология. Не хранит. Чувствует.**

## Что это

Не протокол. Не прибор. Не проект о доверии.

Описание того, что есть. Как гравитация, как энтропия, как резонанс. Не «создаём», а описываем.

## Ядро

- **Всё есть вибрация.** Фотон, звук, тепло, бит, подпись — колебания. Не «объекты, передающие знаки».
- **Состояние — частота.** Не число, не запись. У сложного состояния — аккорд.
- **Среда — взаимодействие вибраций.** Не сеть, не контейнер. Поле *есть* сумма волн.
- **Доверие — резонанс.** Не проверка, не подпись, не голосование. Согласованность.
- **Память — деформация связи.** Русло. Не архив, не лог. Физическое последствие.
- **Цифровой мир построен на отделимой вибрации.** Знаки, числа, байты — почта. Entrain — о неотделимой: о физике.

## Главное

Проблема доверия существует только в почтовой онтологии. В этом описании её **нет** — не решена, а отменена: нет отправителя, нет сообщения, нет подписи.

## Структура

| Путь | Что там |
|---|---|
| `book/` | книга: `ENTRAIN.md` — текст от онтологии, `README.md` — журнал |
| `julia/kuramoto/` | математика онтологии: `basic.jl` — десять вибраций и их аккорды, `consistency.jl` — тридцать пять утверждений описания друг против друга, `simulations.jl` — то же в движении; сцены главы 22: `modes.jl` — моды: та же среда внутри вибрации, `boundary.jl` — где кончается среда, `seam.jl` — две среды или одна с перемычкой, `counting.jl` — счёт: обертоны не написаны, а сосчитаны |

## Запуск

`julia` из juliaup (канал 1.10), из корня хранилища:

    julia julia/kuramoto/basic.jl          # прочитать числа
    julia julia/kuramoto/consistency.jl    # сверить описание с собой
    julia julia/kuramoto/simulations.jl    # увидеть то же в движении
    julia julia/kuramoto/modes.jl          # прочитать: среда внутри вибрации
    julia julia/kuramoto/boundary.jl       # прочитать: где кончается среда
    julia julia/kuramoto/seam.jl           # прочитать: две среды с перемычкой
    julia julia/kuramoto/counting.jl       # прочитать: обертоны не написаны, а сосчитаны

Первое — чтение чисел, второе — сверка описания (не мира), третье — движение того же описания; остальные четыре — сцены открытых вопросов главы 22, каждая читается своим файлом. Утверждения сходятся на Julia 1.10 и 1.13; числа чтения привязаны к версии, потому что поток случайных чисел у версий разный.

## Чего это НЕ

Не протокол. Не спецификация. Не API. Не Web3 / DePIN / блокчейн. Не «прорыв». Не «проект, который поможет миру».

Описание не спорит с почтой. Оно просто другое.
