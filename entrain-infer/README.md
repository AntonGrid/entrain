# entrain-infer · M1 + M2

Детектор лжи в часах парка: GLRT по отклонению частоты (или фазы) узла от часов
парка, порог — из объявленного риска α, минимально обнаружимое смещение
`b_min(N, T, σ)` — из измеренного на реальном фоне σ.

Ход 2 (§12 отчёта, `entrain_infer/theorem.py`) — теорема о сговоре: что именно
симметрично и потому ненаблюдаемо. Парк видит только контраст `x − x̄`, поэтому
ложь входит в наблюдение через хорду `√(k(N−k)/N)`, сговор всех N невидим при
любом b, а при k > N/2 статистика срабатывает и называет честных. Ориентация
раскола лежит в ядре: «k лгут на +b» и «N−k лгут на −b» — одно наблюдение. Разбавление
при k лжецах подчиняется потолку `b_min(k)/b_min(1) ≤ (N−1)/max(k, N−k)` с равенством
только на концах k = 1 и k = N−1: лемма о том, почему это потолок, а не равенство, лежит
в шапке `theorem.py` и проверяется тестом, а не подгонкой. Единственный обратный ход —
якорь: объявить часы одного узла эталоном, тогда `b_min` падает с ростом k, но против
одиночки якорь проигрывает обычному GLRT, поэтому оправдан лишь против коалиций больше √N.

## Что запускается

```bash
python bench/fetch.py       # скачать фон (NASA POWER, PVGIS), записать sha256
python -m entrain_infer     # прогнать bench: bench/results.json + REPORT.md + roc.png
python -m pytest            # математика, оценщик, инъекции, теорема
```

`bench/criteria.json` — предрегистрация Хода 1 (α, мощность, критерии, seed), а
`bench/criteria_m2.json` — Хода 2 (девять предсказаний теоремы) — обе написаны до
прогона; отчёт пишет sha256 каждого файла и не меняет их. Все числа в
`bench/REPORT.md` читаются из `bench/results.json`, ни одно не набрано руками:
повторный прогон даёт байт-в-байт тот же `results.json`.

Правки `criteria_m2.json` после дымового прогона записаны в самом файле
(`revision_note`): два критерия были объявлены сильнее, чем позволяет математика,
и ослаблены до того, что доказуемо, — а не подогнаны под данные.

## Статья

`paper/draft.tex` — каркас препринта (M1 + M2): одиннадцать разделов и три
приложения, каждая формула перенесена из `theorem.py`/`detector.py`, каждое
число — из `bench/results.json`. Утверждения помечены макросами
`\proved` / `\measured` / `\assumed`, недописанное — `\gap{...}`.

```bash
python paper/make_tables.py                    # таблицы из results.json
cd paper && pdflatex draft.tex && pdflatex draft.tex
```

`paper/tables/*.tex` не пишутся руками: их генерирует `make_tables.py` из того же
`results.json` (sha256 `334b9939…`), поэтому таблица и отчёт не могут разойтись.
Тезисы статьи: симметрия калибровки (`t(x+c·1)=t(x)`), хорда `√(k(N−k)/N)`,
невидимость единогласной лжи, инверсия при `k > N/2`, потолок `b_min` с
равенством только на концах, якорь как размен.

## Что отчёт не показывает

`bench/REPORT.md` §11 перечисляет границы: α выведен для нормального H₀ (и в
клетке с тяжёлым хвостом объявленный риск не держится — это измерено, а не
замолчано), σ_honest объявлен, а не замерен на живом парке, инъекции покрывают
три способа лгать, а не все.

У теоремы (§12) свои границы, и они другие. Она говорит, чего не увидит **никакой**
тест этой наблюдаемой; она не говорит, что GLRT — лучший тест коалиции (лучший —
тест хорды, и он требует знать S заранее: §12.6, критерий 8). Она ничего не
говорит о сговоре с разными сдвигами у разных узлов, о лжи, зависящей от погоды,
и о подмене истории: там хорда уже не одна, и теорема к ним не применяется.
Полевой раздел §12.4 верен там, где оценка частоты имеет единичный коэффициент
передачи: при T = 24 ч в июле он ~0.005 (клетка слепая из-за оценщика, не из-за
теоремы), поэтому полевые клетки стоят на T = 168 ч.
